# 三明学院建模 · Campus Canvas

手机可用的校园地图。v0.6根据用户提供的带名称卫星截图，核对宿舍、理工楼、雨盖篮球场与实验综合楼名称，补入南区西侧三排宿舍可见屋面。游泳馆和知新楼虽位于截图蓝线外，仍按用户确认的校属关系保留；知新楼仅显示可见屋面片段，完整楼体待补。二维页可缩放、拖动和搜索楼名或原轮廓编号，保留曲线及院落孔洞。新影像已等比配准到原核对坐标用于近似对照，北端和知新楼等区域存在外推，桌面测距框架仍未单独配准；道路、校界和地面足迹待核。立体样片继续沿用v0.4几何，高程未知，不供导航。

[在线访问](https://lanm-code.github.io/sanming-campus-model/) · [二维平面核对](https://lanm-code.github.io/sanming-campus-model/plan.html) · [外形、空间关系与来源](docs/建筑外形与相对关系核对-v0.1.md) · [验证记录](VALIDATION.md)

## 运行

需要Node.js 22.12以上（本机使用24.19）。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发地址 http://127.0.0.1:4173 。dist为静态构建产物，可部署到GitHub Pages子路径。

## 操作与能力

- 平面核对页：左键/单指拖动、光标锚定滚轮缩放、双指捏合、全览和名称/轮廓编号搜索；点击建筑查看来源及待核状态。楼组保留S21/S22、N12/N13/N14分段搜索。虚线表示局部屋面或完整范围未核，不代表正式校界。在线版仅含矢量数据；内嵌新卫星拼图的可调透明度单文件版本仅保留本地，可切换“只看影像”。
- 立体视图：鼠标左键/单指滑动旋转，滚轮/双指缩放，右键/双指平移；点击建筑选取。
- 2D视图：鼠标左键/单指平移；切回2.5D保留查看位置和缩放。
- 全览、按建筑尺寸聚焦、朝北、复位与近似比例尺；窄屏适配地点抽屉及底部详情。
- 蓝色虚线表示截图参考范围；边界外及跨线建筑用灰色参照。可展开图例区分绿地、广场、教学/生活地块、运动场及道路。
- 局部高差依据现场资料表现：行政楼广场上行台阶、北区两级教学平台、南区下坡及篮球场长阶梯、图书馆背面架空层、博学楼与图书馆连接桥示意。
- 名称/编号搜索、综合实验楼1—6F现场索引、收藏与选中楼层本机保存。
- 静止时停止重复绘制场景；标签按缩放与重叠情况显示。WebGL失败时保留清单查找。

## 资料边界

位置使用带坐标影像近似描绘后进入统一米制框。用户高德截图以共同影像地标配准描绘58点参考轮廓，不直接混用GCJ02与WGS84经纬度；配准RMS约5.24参考像素，综合图像/描绘误差估计15—25像素，非测绘校界。外接工作框约0.74×1.28公里只用于取景。学校占地统计和截图主校园参考范围可能口径不同，不用官方总面积强行放大轮廓。

高度、台地范围、道路宽度、曲率、桥跨度及阶梯数量都是可调显示参数。照片支持局部高低关系，不支持整个校园相对基准的实测高程；未核对地形保留参考面，颜色也不能证明未识别建筑的用途。路网缺口及通行性尚未核对；穿入建筑实体或前台阶的冲突片段暂时遮罩隐藏。综合实验楼与博学楼归属待核对；所有教室门位为空，保留真实名称和408前后门独立条目。

生成几何保存于src/campus-data.json，记录来源、不确定状态和隐藏道路长度。地形在局部连接处细分，建筑基底与坡道优先，桥体不抬高桥下参考面；道路与边界几何按材质合批，静止时不重复绘制。参考影像、手机截图及照片保留本地，**不得放入public/review**，构建对此设置阻止检查；仅.gitignore忽略无法阻止Vite复制公开目录。天气、家具编辑、导航和APK在后续实现。移动端已做浏览器尺寸检查，尚未完成Android真机GPU/多指验证。
