# 三明学院建模 · Campus Canvas

手机可用的2.5D校园地图首版工程。当前v0.1.0为核心建筑互动样片，不是已完成测绘的校园导航。

## 运行

需要Node.js 22.12以上（本机使用24.19）。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发地址 http://127.0.0.1:4173 。dist为静态构建产物，可部署到GitHub Pages任意子路径。

## 当前能力

三座参考现场照片的简化建筑；旋转、缩放、平移、俯视切换与复位；建筑与真实房间名称搜索；现场“综合实验楼”1—6层索引；收藏与选中楼层本机保存；窄屏底部详情面板；WebGL失败时继续使用清单。地图单指/鼠标左键拖动平移，双指缩放旋转；旋转按钮支持45度转向。

## 资料边界

地图布局和高度是样片显示参数，未地理配准，不供导航。综合实验楼与博学楼归属待核对，索引单独保留；教室坐标全部为空。名称及楼层来自用户现场照片67，可能存在用途调整；真实位置不足时不生成假点位。建筑入口关系来自用户照片47、64及说明。建筑照片58、98支持外形概括，未精确测量层数或尺寸。学校官方示意图：https://xiaoqing.fjsmu.edu.cn/map 。

原始照片、个人路径、恢复记录与账号资料不纳入该代码仓库。天气、家具编辑、课表同步、导航和APK后续实现。
