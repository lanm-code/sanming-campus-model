# 三明学院建模 · Campus Canvas

手机可用的2.5D校园地图。当前v0.2.0是全校园布局核对版：3座照片参考模型、44个近似建筑轮廓、道路与运动场地。完整校界、全部建筑身份与校园高差仍待核对，不供导航。

[在线访问](https://lanm-code.github.io/sanming-campus-model/) · [外形、空间关系与来源](docs/建筑外形与相对关系核对-v0.1.md) · [验证记录](VALIDATION.md)

## 运行

需要Node.js 22.12以上（本机使用24.19）。

```sh
npm ci
npm run dev
npm test
npm run build
```

开发地址 http://127.0.0.1:4173 。dist为静态构建产物，可部署到GitHub Pages子路径。

## 操作与能力

- 立体视图：鼠标左键/单指滑动旋转，滚轮/双指缩放，右键/双指平移；点击建筑选取。
- 2D视图：鼠标左键/单指平移；切回2.5D保留查看位置和缩放。
- 全览、按建筑尺寸聚焦、朝北、复位与近似比例尺；窄屏适配地点抽屉及底部详情。
- 名称/编号搜索、综合实验楼1—6F现场索引、收藏与选中楼层本机保存。
- 静止时停止重复绘制场景；标签按缩放与重叠情况显示。WebGL失败时保留清单查找。

## 资料边界

位置使用带坐标影像近似描绘后进入统一米制框；不混用高德和WGS84。绿色底板是建模工作范围，外接框约0.74×1.28公里，不是完整校界。公开地图候选校界与学校官方占地统计差异明显，保留待核对状态。

高度、道路宽度、曲率和台阶都是显示参数。路网缺口及通行性尚未核对；穿入建筑轮廓的冲突片段暂时遮罩隐藏。综合实验楼与博学楼归属待核对；所有教室门位为空，保留真实名称和408前后门独立条目。照片用途可能变化。

生成几何保存于src/campus-data.json，记录来源、不确定状态和隐藏道路长度。参考影像/照片保留本地，**不得放入public/review**，构建对此设置阻止检查；仅.gitignore忽略无法阻止Vite复制公开目录。天气、家具编辑、导航和APK在后续实现。移动端已做浏览器尺寸检查，尚未完成Android真机GPU/多指验证。
